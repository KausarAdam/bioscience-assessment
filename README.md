# Distributor Resource Portal

WordPress page template built for BIOSCIENCE GmbH assessment.

## Setup
- Install WordPress
- Install ACF plugin
- Add File URL field to Posts
- Create posts across 2 categories (Brochures, Training Materials)
- Apply this template to a page
- Password protect the page

## Files
- `distributor-portal.php`: Page template with WP_Query loop

## Password
Page password: Set up from the wp-admin dashboard
